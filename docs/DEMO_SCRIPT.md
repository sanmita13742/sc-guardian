# Demo script (≈ 10 minutes) — "from detection to a validated, applied fix"

Sample application: **OWASP/NodeGoat** (public, containerised: Dockerfile + docker-compose + GitHub workflows, ~1,200 npm packages). Clone it (`git clone https://github.com/OWASP/NodeGoat`) if you want to demo the local-folder flow. Start the app: `python -m streamlit run app.py` → http://localhost:8501.

1. **Discover (1 min)** — *Repository Scan*: paste `https://github.com/OWASP/NodeGoat` **or the path of your local NodeGoat folder**, then **Start Security Scan**. Narrate the live agent checklist (Recon → Pipeline → SBOM → Graph → Vulnerability → Verification → Investigator → Threat → Risk → Remediation → Validator → Memory → Analyst) and the decision log (scanner fallback, fusion, registry resolution).
2. **SBOM & supply-chain view (1 min)** — *SBOM Explorer → Metadata*: metadata completeness, digests verified against the registry, install-script packages. *SBOM file* tab: the fused CycloneDX with `sc-guardian:provenance:*`. *Dependency Graph → Dependency Tree*: bottom-up "who pulls this in" for a vulnerable transitive package.
3. **Detect non-CVE risks (1 min)** — *Pipeline & Containers*: `node:12-alpine` and `mongo:4.4` end-of-life, unpinned images, outdated GitHub Action majors, no explicit token permissions. *Suspicious Changes → Package risk*: deprecated direct dependencies, install scripts without provenance.
4. **Prioritise with evidence (2 min)** — *Vulnerability Findings*: 311 raw findings → verdicts (reachable / possibly reachable / test-only / no import evidence). Note the two scales: **CVSS** severity in the header and table, and **contextual risk** (Risk / Score / Priority). Open a P0/P1 finding → **Risk breakdown** (the four factors and why), then **Investigation** (verdict, confidence basis, EPSS, tool trace and evidence ids).
5. **Resolve and apply (3 min)** — *Remediation*: pick a proposal (e.g. `express 4.16.4 → 4.22.0`). Show the rationale, measured effect and diff.
   * **GitHub scan:** approve with a reason, then export the `.patch` / PR text or create the remediation branch; the audit trail records it.
   * **Local folder:** only **🔧 Resolve** is offered. Press it and narrate the clone → apply → lockfile refresh → rescan → compatibility → tests steps. Show the result (findings before/after, newly introduced, declared-compatibility table, any warning), then **✅ Accept & Apply Changes** — the counters at the top move (Open ↓, Applied ↑, **Findings remaining** ↓). Pick a second proposal: Resolve again, and note overlapping fixes are not double-counted. **↩️ Undo** restores the files. Rescan the folder to show the fixed findings are gone.
6. **Report (1 min)** — *Fix Report*: every applied fix with its scoring before/after, the real diff, the validation record, and **⬇ PDF** (one page per fix, or **All fixes**). Terminal: `python guardian.py gate latest --policy default` → exit code 1 (policy gate). *Reports*: Guardian report (MD/HTML), SARIF, VEX.
7. **Containers (optional, 1 min)** — with `CONTAINER_SCAN_ENABLED=true` and Trivy installed, the image's OS packages appear as findings; the Remediation page proposes a Dockerfile `RUN` layer with the distro's fix versions, and Resolve builds the patched image and rescans it (Docker + Trivy needed).
8. **Continuous monitoring (30 s)** — *Monitoring* (GitHub scans): Watch → Run monitor now; alerts appear when an advisory is disclosed after the scan (`python guardian.py monitor` for cron / Actions).
9. **Responsible AI (30 s)** — *Architecture → AI, approvals & safety*; *Settings & Health* shows LLM disabled/enabled. With `LLM_API_KEY` set: tick **Optional LLM reasoning**, rescan; a finding shows "AI-assisted, grounded", and a rejected proposal shows the gate's reason.

Fallbacks: no Syft/Trivy → built-in rule engine (the grouping of findings under direct dependencies is richer with Syft); offline → lockfile/scanner metadata only (stated in limitations); no Docker → project tests and image builds are skipped, the fix is marked unverified and its warning must be acknowledged before Accept.
